# Beauty Palu 2026 — CRUD Update

Versi ini menambahkan aksi yang terlihat jelas pada seluruh tabel:
- Lihat
- Edit / Update
- Hapus
- Tambah
- Export CSV
- Search global
- Form modal per modul

Modul: Buying Plan Ads, Finance, Task & Timeline, Tenant, Influencer/KOL, Agenda/Schedule.

Catatan: UI CRUD pada paket ini memakai state aplikasi. Koneksi persistensi Supabase perlu diterapkan pada handler database untuk membuat perubahan permanen lintas perangkat.
